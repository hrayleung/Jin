# Model census — November 10, 2026

Window: November 3–10, 2026. Enumerated all 37 first-class providers from `ProviderType` and `DefaultProviderSeeds`; the generic `openaiCompatible` provider is out of scope. Each provider received a separate official-domain search using its name plus “models”, “API” or “changelog” and the date window, followed by direct fetches of its model inventory and release notes/library. The complete census was written before implementation.

Added 18 exact catalog records, covering 20 provider/model combinations through the shared Anthropic/Managed Agents catalog. Existing adapters, seeds, Add Model inference, settings resolution (including legacy rows), support badges and capability menus consume these records. Blocked entries below retain their reasons; they receive no full-support badge or seed. “No-new” means no new callable ID was verified in the checked official sources, not a guarantee that an undocumented route does not exist.

OpenRouter's `created`, DeepInfra's `create_ts`, and Vercel's `released` fields were used for the date filter. Vercel's common `created` value and MorphLLM's request-time timestamps were not treated as release dates.

Vercel and Ramp Router did not publish a default effort in the fetched inventory, so those new records leave it unset. Vercel Ember advertises image/PDF input, not audio/video; Jin keeps PDF rasterization on that gateway. OpenRouter Ember uses the existing audio encoding. Its advertised video input stays disabled pending the repository's required live gateway probe: `ModelCatalogTests` documents that model-list video claims alone have previously failed on the wire. Native Meta uses Responses file/media inputs. RunInfra's recommended initial output budget of 16,384 is not its published maximum.

Direct Claude requests use `thinking.block_binding.prefix_mismatch_behavior: "drop_block"` and the `thinking-binding-controls-2026-08-01` header. This permits changed history/tools without a stale thinking-prefix rejection. The new fast-mode routes use `speed: "fast"` without the older fast-mode beta header. RunInfra retains DeepSeek V4.1 Flash as its preferred seed; Meta retains Muse Wonder. The fast-mode menu no longer claims a single price or beta status for every supported model.

Omni 1.2 uses `POST /interactions`, image/video inputs and a video response format. UI offers 360p, 720p, 1080p, 4K and 16:9/9:16; higher resolutions request URI delivery. Duration remains prompt-controlled (3–15 seconds, 3–10 for interpolation/extension); Veo-only duration/seed/person controls are removed when switching to Omni. The hosted OpenRouter/Vercel Omni routes are separate contracts and are not enabled by the native ID.
