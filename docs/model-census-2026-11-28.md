# Model census — November 28, 2026

The search covered November 19–28, 2026, using the dates published by each provider. `ProviderType` and `DefaultProviderSeeds` enumerate 37 first-class providers. The generic `openaiCompatible` provider is out of scope.

The comparison builds on the [November 19](model-census-2026-11-19.md) census. This update adds 29 callable model routes across 11 providers and records all blocked or adapter-gated releases discovered in the window.

Each provider had an official-domain search and direct catalog and release-note or library fetch. Live public model inventories from OpenRouter (chat, video, image), Vercel AI Gateway, DeepInfra, OpenCode Go, SambaNova, Zyphra, and MorphLLM were diffed against `ModelCatalog.orderedRecords`.
