# Model Census — 2026-11-15 (Window: Nov 8–15, 2026)

Weekly official-docs model census across all **37 first-class `ProviderType` providers** in [`ProviderTypes.swift`](../Sources/Domain/ProviderTypes.swift). `.openaiCompatible` (38th case, generic BYOK endpoint) is explicitly out of scope.

> **Legend**
> - `added`: New chat/reasoning/multimodal model(s) verified against official docs/APIs and added across catalog, seeds (`isSeeded` where seeded), capability registry, resolver, adapters, and tests.
> - `already-cataloged`: Official release in the Nov 8–15 window already present in Jin's catalog and verified unchanged.
> - `no-new`: Official changelog/model endpoint shows no new model releases in Nov 8–15 (or non-model feature updates only).
> - `blocked`: Candidate lacks public/documented callable request contract or API availability (e.g., marketing directory only, allowlisted preview).
> - `blocked-adapter`: Official model uses an endpoint/modality Jin's provider adapter does not implement (Decisions/Evaluation API, image-generation-only on non-image adapter, Dedicated-only tier, Unity AI Gateway).
