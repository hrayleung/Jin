# Model census — November 19, 2026

The search covered November 12–19, 2026, using the dates published by each provider. `ProviderType` and `DefaultProviderSeeds` enumerate 37 first-class providers. The generic `openaiCompatible` provider is out of scope.

The comparison includes the [November 15](model-census-2026-11-15.md) and [November 18](model-census-2026-11-18.md) censuses. This update adds 14 routes across nine providers and corrects request handling for several cataloged models.

Each provider had an official-domain search and direct catalog and release-note or library fetch. The results were compared with the provider's exact IDs in `ModelCatalog.orderedRecords`. OpenRouter also publishes separate video and image inventories. OpenRouter's `created`, Vercel's `released`, DeepInfra's `create_ts`, OpenCode Go's `release_date`, and Zyphra's `releaseDate` identify dated entries. Vercel and OpenCode Go's common `created` values and Morph's response-time timestamps were excluded from the date comparison.

## Implemented request contracts

- OpenAI and OpenAI WebSocket use the same GPT‑6.2 model records. Both IDs have 1,050,000 context, 128,000 output, and low through max reasoning with a medium default. Jin sends reusable system instructions in Responses developer messages and offers the documented 30-minute and 12-hour cache options. The composer offers Default, Priority and Ultrafast for these IDs. [Astra model card](https://developers.openai.com/api/docs/models/gpt-6.2-astra), [Sol model card](https://developers.openai.com/api/docs/models/gpt-6.2-sol), [migration guide](https://developers.openai.com/api/docs/guides/latest-model/gpt-6.2-astra), [prompt caching](https://developers.openai.com/api/docs/guides/prompt-caching), [Ultrafast](https://developers.openai.com/api/docs/guides/ultrafast-mode).
- Gemini API and Vertex use the single-response limit of 65,536 tokens in an overall context of 1,048,576. Neon sends four supported thinking levels through `XHIGH`, uses implicit caching, and accepts image, audio, video and PDF inputs. The OpenRouter, Vercel and Ramp records use their own limits and effort bands. OpenRouter lists 943,718 output tokens for its top provider and 65,536 for one other route. For Neon on Vercel and OpenRouter, Jin prepares PDF attachments before sending them. [Gemini API card](https://aistudio.google.com/docs/models/gemini-4-neon), [Vertex card](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/gemini/4-neon), [OpenRouter routes](https://openrouter.ai/api/v1/models/google/gemini-4-neon/endpoints), [Vercel card](https://vercel.com/ai-gateway/models/google/gemini-4-neon), [Ramp card](https://router.com/models/gemini-4-neon).
- OpenCode Go sends Qwen4 Max through Messages with `thinking.type` and `output_config.effort`. Hy4 flash Free uses Chat Completions with `reasoning_effort`. Qwen4 Max accepts images through Jin's Messages adapter. Its advertised video input stays pending a compatible Messages media path. DeepInfra's Qwen4 Max uses its documented boolean reasoning toggle with the existing video input route. [OpenCode Go catalog](https://opencode.ai/inference/go/v1/models), [Qwen Messages reference](https://www.alibabacloud.com/help/en/model-studio/anthropic-api-messages), [DeepInfra Qwen schema](https://api.deepinfra.com/models/Qwen/Qwen4-Max/schema/openai-chat-completions), [DeepInfra Inkling schema](https://api.deepinfra.com/models/thinkingmachines/Inkling-2-Small/schema/openai-chat-completions).

The published Hydrogen contract is text-only. [Databricks routing](https://docs.databricks.com/aws/en/machine-learning/model-serving/query-chat-models), [reasoning controls](https://docs.databricks.com/aws/en/machine-learning/model-serving/query-reason-models).
