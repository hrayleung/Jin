## Hosted copies

- GPT-6.2 Astra and Sol appear in OpenRouter and Vercel's public feeds. GitHub confirmed Copilot availability by display name. The other gateway sources in the table yielded no callable IDs for these models.
- Gemini 4 Hydrogen was already cataloged on OpenRouter and Vercel. Databricks documents an exact Unity Gateway model service. Perplexity and GitHub Copilot announced availability on different or unverified routes.
- Inkling 2 Small was already cataloged on OpenRouter, Vercel, Together, Cloudflare, DeepInfra and Modal. The Nov 12 upstream update also names Fireworks and Baseten. No public Fireworks API ID was verified. Baseten's model card documents dedicated deployments with separate context limits. [Upstream release](https://thinkingmachines.ai/news/inkling-2-small/)
- Qwen4 Max appears on OpenRouter, Vercel and DeepInfra. Hy4 Flash appears on OpenRouter and Vercel. Their gateway limits differ across these feeds. Ling 3.2 Flash (free) was already cataloged on OpenRouter. Flint was verified on Vercel.

## Adapter gaps

- OpenAI moderation `omni-moderation-csam-latest` and OpenRouter's four GPT-6.2 `:batch` IDs require different request surfaces.
- Vercel video and image generation IDs are `bytedance/seedance-2.5-flash`, `bytedance/seedream-5.5`, `microsoft/mai-image-2.7` and `microsoft/mai-image-2.7-flash`. Evaluation IDs are `heygen/heygen-decision-1`, `heygen/heygen-decision-1-turbo`, `liquid/d1.2`, `liquid/d1.2-ultra`, `microsoft/decision-1.1` and `parallel/parallel-decisions-fast`. Jin's Vercel chat route does not implement those request types.
- Together announced `nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B` and `nvidia/NVIDIA-Nemotron-3.5-Super-VL-120B-A12B` for fine-tuning and `nvidia/NVIDIA-Nemotron-3.5-Super-VL-120B-A12B-BF16` for post-training. Those entries do not establish new shared chat routes.


## Request and metadata details

- Native OpenAI GPT-6.2 uses Responses for function tools. Jin exposes Pro reasoning, web search, Code Interpreter, native PDFs and the Ultrafast service tier on the verified routes. [OpenAI migration guide](https://developers.openai.com/api/docs/guides/latest-model), [reasoning](https://developers.openai.com/api/docs/guides/reasoning), [Ultrafast](https://developers.openai.com/api/docs/guides/ultrafast-mode)
- Vercel GPT-6.2 uses Responses for web search and inline PDFs. The two explicitly documented base IDs offer the Ultrafast tier. OpenRouter's GPT-6.2 routes send PDFs as Chat Completions file parts. [Vercel GPT-6.2](https://vercel.com/changelog/gpt-6-2-astra-and-sol-now-available-on-ai-gateway), [OpenRouter PDF inputs](https://openrouter.ai/docs/guides/overview/multimodal/pdfs)
- DeepInfra's exact Inkling 2 Small card documents a 262,144-token serving window, even though its public feed reports 1,048,576 under `max_tokens`. The adapter uses the documented `reasoning_effort` values. DeepInfra Qwen4 Max leaves undocumented effort values and output limits unset. OpenRouter Qwen4 Max video input is pending a live gateway probe. [DeepInfra Inkling card](https://deepinfra.com/thinkingmachines/Inkling-2-Small), [DeepInfra Qwen card](https://deepinfra.com/Qwen/Qwen4-Max)
- Databricks Hydrogen is available via Add Model using `system.ai.gemini-4-hydrogen`. The Unity route uses workspace authorization and cross-geography routing. [Databricks model card](https://docs.databricks.com/aws/en/machine-learning/foundation-model-apis/supported-models#google-gemini-4-hydrogen), [Unity Gateway chat route](https://docs.databricks.com/aws/en/machine-learning/model-serving/query-chat-models)
